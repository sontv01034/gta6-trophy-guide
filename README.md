A complete offline guide and checklist tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, built for the make.fun bounty of the same name.

## What it covers

- **Every trophy** — the official 55 (1 platinum, 2 gold, 6 silver, 46 bronze), each with its official name, description and grade, and a guide written in our own words that cites its source beside it.
- **Platinum roadmap** — 8 stages in order: story, side characters, the one missable, activities, collectibles, crime and money, clean-up and 100%, then the platinum. About 200 hours all in.
- **The one missable** — Positive Mental Attitude (meditate at every spot) is flagged by GTABase and PowerPyx as the only trophy that can be missed; Lucia's Chapter 1 balcony meditation disappears after that chapter, and the game has no mission replay.
- **Tracker** — tick trophies off as you earn them; progress saves in localStorage, exports to a file and imports back. Filters by story, missable, collectibles, activities and online (there are no online trophies — all 55 are single-player). Spoiler mode hides story trophy names and descriptions until earned.

## How to use it

Serve `app/` with any static file server and open `index.html`, or try it locally:

```sh
cd app && python3 -m http.server 8080
```

No build step, no network requests at run time, no Rockstar logo or artwork.

## Sources

Names, descriptions and grades are the official list as PlayStation publishes it, as listed by Exophase and PSNProfiles. Guides are our own words; each cites its source (Press Start, Output Lag, Sixshore, EGamers, GTA Vice City Hub — see the Sources section in the app).
